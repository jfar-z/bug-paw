# 工作流索引与独立定义

ComfyUI 和 DAG 的列表保存在应用数据库 `app/bugpaw.sqlite3` 的 `workflow_index` 表中，以 `(kind, id)` 为主键。`kind` 分别为 `comfyui` 和 `dag`；`definition_file` 保存 `<工作流ID>.json`，`summary_json` 仅保存名称、时间、版本及列表计数等摘要，节点、脚本、连线、原始工作流与参数映射不进入数据库。

| 类型 | 定义目录（相对数据根目录） |
| --- | --- |
| ComfyUI | `app/aigc-workflows/definitions/<工作流ID>.json` |
| DAG | `app/workflows/definitions/<工作流ID>.json` |
| DAG 运行快照 | `app/workflows/runs/<运行ID>.json` |

文件名不包含内容哈希或版本后缀。新增、更新、删除只修改对应工作流文件。列表查询不扫描定义文件；单个文件缺失或损坏时，该工作流详情与执行明确报错，其他工作流仍可读取。

## 手工修改

- 使用 UTF-8 修改对应 JSON，保留顶层 `id` 与文件名一致。不要将该文件替换为只有 ComfyUI 节点的裸 JSON；原始 ComfyUI 工作流在 `raw` 字段，输入输出映射和节点元数据在同一文件的对应字段。
- ComfyUI 每次读取会从 `raw` 重新解析节点、连线和原始摘要，因此修改节点或参数后无需重启。DAG 直接读取 `nodes`、`edges` 和节点配置。正在运行的任务继续使用已取得的快照。
- 手动修改属于离线维护，先关闭编辑页并停止写入，推荐停服后编辑，再检查 JSON 格式并原子替换文件。避免人工编辑与应用保存同时进行；文件自身不会向数据库提交新的并发版本。
- 列表摘要以数据库为准。手动修改名称、说明、发布状态或节点数量后，详情使用新文件内容，但列表摘要需在页面打开并保存一次后更新。不要直接修改 ID、文件名或数据库定位字段。
- `.pending.json` 和 `.tmp` 是文件事务恢复材料，不属于可编辑工作流。应用用数据库提交标记判断保留新文件还是恢复旧文件；这仅用于本存储的写入恢复，不会读取旧聚合文件或自动迁移业务数据。

## 独立离线迁移

应用数据库升级只创建空索引表，不导入 `app/aigc-workflows.json` 或 `app/workflows/definitions.json`。首次切换新存储必须先停服，再运行独立脚本。部署脚本不会调用迁移。

在项目要求的 Node 镜像、已安装依赖的源码目录中执行；数据和备份必须挂载到容器，脚本使用对数据目录有写入权限的用户：

```sh
node --import tsx scripts/migrate-workflow-storage.ts \
  --data-dir /data \
  --backup-dir /backup/workflow-storage-20261030
```

上述命令仅预检。确认计数后使用相同参数添加 `--apply` 执行。备份目录必须位于数据目录之外，且尚不存在。脚本持有与应用相同的实例锁，防止迁移期间服务启动。

脚本先备份 SQLite 一致性快照、两类旧聚合文件及 DAG 运行快照，写入 SHA-256 校验清单并回读核对，再创建数据库表、写独立定义、事务导入索引。原 ID、正文、映射和运行快照保留不变；重复 ID、无效引用或与目标冲突会拒绝导入。定义写入和数量、数据库完整性校验全部通过后，才删除已备份的两个精确旧聚合文件。备份目录及文件分别使用 `0700`、`0600`。

定义导入过程中中断时保留原聚合文件，重跑须使用新的备份目录；相同内容允许继续，任何不同内容均拒绝覆盖。迁移成功后旧文件已移除，再次执行会明确拒绝。备份中的 `report.json` 记录本次计数。

## 回滚

保持服务停止，先确认目标数据目录和本次迁移备份。校验 `manifest.json` 后，将备份数据库恢复为 `app/bugpaw.sqlite3`，恢复 `aigc-workflows.json` 和 `dag-definitions.json` 到各自旧位置，再切回部署前镜像。恢复数据库时必须确保旧连接均已关闭，并正确处理当前数据库的 WAL/SHM 文件；不得在运行中的数据库上直接覆盖。

独立定义文件可保留用于排查，旧代码不读取它们。迁移后如产生了新业务数据，直接恢复整个数据库会回退这些数据，需另行制定恢复范围。DAG 运行快照默认不改写；只有确需回退运行记录时才从 `dag-runs/` 恢复。

自动化验证覆盖列表和正文分离、手工编辑生效、版本冲突、文件损坏隔离、写入失败回滚、进程中断恢复、迁移前备份、两类数据逐项相等、原 ID 和引用保留、运行快照不变及应用不自动迁移。
