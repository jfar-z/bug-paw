# 浏览器执行验收清单

- 配置页：桌面与移动端、深浅主题、在线、离线、加载、部署不可用、保存冲突。
- 工具：九个工具 Schema 根节点均为 object；高风险三项不在新 Agent 默认权限中。
- 公网：HTTPS 成功；HTTP、私网、元数据、DNS 重绑定和 WebSocket 拒绝；Fake-IP 仅在部署侧显式登记 CIDR 后可用。
- UI：精确 Origin 的输入、提交、上传分别控制；敏感字段始终拒绝。
- 生命周期：阻塞队列更新、取消、30 秒心跳、孤儿回收、总时限、Run 结束清理。
- 文件：静态 HTML 相对资源、路径穿越和符号链接拒绝；截图与下载只留下预期产物和安全 manifest。
- PWA：浏览器配置页可离线读取；API、审计、快照、截图、下载与产物不进入 Cache Storage。
- 部署：browser/full Compose 校验；内部密钥 mode 600 且不打印；Worker 与代理使用同一专用 UID 且无宿主端口；真实栈覆盖标准 407 代理认证挑战。
