# Personal Web Agent 领域语言

本上下文描述个人 Web Agent 工作台中的核心业务概念，用于区分长期存在的 Agent、短期会话与 Pi 原生运行配置。

## Agent 与会话

**Agent**：
长期存在且彼此独立的工作主体，创建时绑定唯一工作目录，并拥有独立的角色、行为规则、配置和长期状态。
_避免使用_：Pi Session、聊天、模型

**Agent Profile**：
Web 服务维护的 Agent 身份与配置记录，包含稳定标识、名称、头像、固定工作目录和默认运行配置。
_避免使用_：Pi 原生 Agent 配置、Session 配置

**角色与行为**：
持续定义 Agent 身份与协作对象的系统指令，由角色与职责、行事作风、规则和用户四个 Markdown 分区组成。
_避免使用_：Skill、Prompt 模板、动态计划

**用户设定**：
用户稳定的背景、偏好、沟通语言与交付习惯，不包含当前对话的即时任务。
_避免使用_：当前用户消息、Agent 职责、长期目标

**规则**：
Agent 持续遵循的约束集合，可在一个 Markdown 分区内表达工作原则、强制要求和禁止事项。
_避免使用_：独立的工作原则、强制规则或禁止事项字段

**工作目录**：
Agent 生命周期内固定不变的文件空间，也是该 Agent 的 Pi 项目级配置和资源作用域。
_避免使用_：Session 目录、可切换项目目录

**Session**：
归属于某个 Agent 的一次可恢复对话；同一 Agent 的多个 Session 共享工作目录和 Agent 配置。
_避免使用_：Agent、工作目录

**Turn**：
Session 中由一条用户请求触发的一次完整处理过程，包含请求受理、Agent 推理、工具调用、结果输出和结束状态。同一 Session 同一时刻最多有一个活动 Turn。
_避免使用_：整段 Session、单个流式文本片段

**Session Event**：
服务端向客户端发布的 Session 增量变化，例如 Turn 被受理、文本增量、思考增量、工具状态、模型变化和终止状态。事件在所属 Session 内具有单调递增的序号。
_避免使用_：Pi 原生消息、数据库记录

**Session Projection**：
客户端或服务端在某一时刻可恢复的 Session 完整视图，由 Pi 原生消息、当前活动 Turn 和必要的增量状态共同组成。
_避免使用_：事件日志、长期审计日志

## 模型与配置

**模型目录**：
全局共享的 Provider 与模型集合，供各 Agent 选择默认模型，并允许 Session 临时切换模型。
_避免使用_：Agent 模型副本

**Pi 全局配置**：
所有 Agent 共享的 Pi 原生设置、模型定义和凭证配置。
_避免使用_：Agent Profile

**Agent 配置**：
在 Pi 全局配置之上对单个 Agent 生效的配置，作用域由该 Agent 的固定工作目录确定。
_避免使用_：Session 配置

**运行时状态**：
Pi SDK 根据当前配置、凭证和 Provider 动态计算的模型可用性及错误，不属于持久化配置字段。
_避免使用_：模型状态配置

## 数据所有权

**BugPaw 应用状态**：
由 Web 应用创建并负责一致性的结构化业务数据，包括身份、Agent Profile、Session 归属与归档状态、定时任务、知识库元数据和配置变更记录。
_避免使用_：Pi 原生配置、Pi Session 消息、工作目录文件

**Pi 原生数据**：
由 Pi SDK 定义格式与语义的配置和会话数据。BugPaw 可以通过受控适配器调用或更新，但不得把自身数据库作为这些数据的另一个事实来源。
_避免使用_：BugPaw 应用状态
