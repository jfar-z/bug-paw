# 运维 Runbook

## 健康与诊断

从部署根执行 `docker compose ps bug-paw-web`，健康探针为 `curl --fail --silent --show-error http://127.0.0.1:7080/healthz`。配置中心诊断用于查看挂载、目录可写性、资源加载与后台错误摘要，不返回敏感内容。

## 数据库检查

先停止容器，再对备份副本执行 `sqlite3 bugpaw.sqlite3 'PRAGMA integrity_check;'`。结果必须为 `ok`。运行中的 WAL 数据应通过应用正常关闭或 SQLite 备份 API收敛，禁止只复制主数据库文件后宣称备份完成。

## 备份与恢复

备份前解析并人工核对源绝对路径，停止 `bug-paw-web`，确认无写入者；同时保存原目录快照和 tar.gz，生成文件清单与 SHA-256，并执行校验。恢复前再次停止容器，校验归档 SHA-256，把当前目录移动为独立回退点，再原子替换为已验证快照。禁止对 `/`、用户目录、部署根或未解析变量执行递归删除。

## 常见故障

- `INSTANCE_ALREADY_RUNNING`：确认是否已有容器；无进程时检查实例锁所有者，不直接删除活跃锁。
- SSE 重连：先检查浏览器网络和反向代理缓冲；事件缺口由 Projection 自动恢复。
- 任务积压：查看诊断后台错误码、Runtime 是否繁忙和任务最近运行；不要并发手工重复触发。
- 数据库异常：停止写入，保留数据目录，使用最近验证备份恢复；不要在原件上直接修表。
