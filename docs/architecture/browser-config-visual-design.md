# 浏览器执行配置页视觉收敛设计

## 目标

让“浏览器执行”页面在视觉和交互上与配置中心的联网搜索、语音合成、语义检索页面保持一致，解决连续边框、嵌套卡片和虚线提示框造成的割裂感，同时完整保留现有配置能力。

## 设计模式

- 模式：Redesign · Preserve
- 视觉语言：BugPaw 配置中心现有的扁平表单与细分隔线
- 视觉变化：2/10
- 动效强度：1/10
- 信息密度：7/10
- 素材依赖：1/10
- 品牌一致性：10/10

这是既有产品页面的视觉修正，不引入新的配色、字体、圆角、阴影、动效或导航结构。

## 保留内容

- 页面路由、标题、说明文案和配置中心导航行为。
- 六个章节及其现有顺序。
- 全部表单字段、字段顺序、限制值、默认值与保存逻辑。
- 服务状态、离线状态、部署缺失、保存成功及错误反馈。
- 受信任 Origin 的精确匹配、权限开关、添加和删除行为。
- 桌面与窄屏响应式行为、键盘操作和无障碍名称。
- PWA 离线只读快照能力。

## 视觉结构

### 页面与章节

页面继续使用 `configuration-page`。每个章节采用配置中心通用的 `configuration-form-card` 结构，仅显示章节顶部细分隔线、编号、标题和右侧摘要，不形成封闭卡片。

移除 `SettingsSection` 带来的额外内容内缩，使字段与联网搜索、语音合成页面遵循同一水平基线。章节之间通过自然留白和顶部细线区分。

### 状态与公开范围

服务启用开关使用标准 `configuration-capability-toggle` 表单行。Worker、活动 Context 和排队任务沿用紧凑元数据行；测试按钮作为章节内次要操作，不增加外层容器。

“所有公网 HTTPS 站点”从虚线提示框改为普通说明行：主文案与安全边界说明直接位于章节内容中，以文字层级区分，不增加边框。

### 数值设置与权限

公开浏览范围、资源池和浏览产物的数值字段全部使用标准 `configuration-form-card label` 行。每行由左侧名称和右侧输入组成，行与行之间仅使用细分隔线。

本地静态页面和 Origin 权限不再使用 `tool-permission-grid` 小卡片。每个权限改为标准开关表单行，保持原有复选框语义和标签。

### Origin 管理

新增 Origin 使用一个标准表单行：左侧为字段名称与简短说明，右侧为输入框和“添加 Origin”按钮组成的操作组，不使用 `configuration-create-panel` 外框。

已有 Origin 使用扁平分组：Origin 地址与删除按钮构成小标题行，下方依次显示权限开关。多个 Origin 之间使用留白和单条细分隔线，不嵌套 `configuration-form-card`。

无 Origin 时显示普通帮助文字，不使用空状态卡片。

## 响应式规则

- 桌面端沿用配置中心两列表单行。
- 窄屏下沿用现有媒体查询，将标签和控件堆叠为单列。
- Origin 输入与添加按钮在空间不足时换行，输入框优先占满可用宽度。
- 不引入水平滚动；固定保存栏不得遮挡最后一个字段。

## 技术边界

- 优先组合既有配置中心类名和组件，不扩散全局样式影响。
- 若必须增加样式，只添加浏览器页局部类，并控制 Bundle 预算。
- 不修改后端、配置协议、持久化结构或安全策略。
- 不更改其他配置页面的 DOM 和视觉表现。

## 验收标准

1. 页面主体不存在连续封闭卡片、虚线提示框或权限小方框矩阵。
2. 六个章节的标题、字段和分隔方式与联网搜索、语音合成页面一致。
3. 所有字段、权限与 Origin 操作仍可访问和保存。
4. 桌面、深色模式和 390px 窄屏无横向溢出，页面可以滚动到底部。
5. 配置侧边栏行为保持不变。
6. 回归测试、类型检查、架构检查、Web/PWA 构建及 Bundle 门禁通过。

## 回退方案

本次仅调整浏览器执行页的组件结构和局部样式；如视觉或响应式验收不通过，可单独回退该页面提交，不影响浏览器执行服务与配置数据。
