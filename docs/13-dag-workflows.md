# DAG 工作流

工作流是独立的一级工作台，与 AIGC 工作台中的 **ComfyUI 工作流** 分开管理。二级入口为工作流列表、运行工作流、运行记录。管理员可以拖动节点、连接控制边，并在右侧配置参数；数据引用使用稳定节点 ID 和输出名称，自动补齐必要依赖，禁止环路。判断分支必须先连接 IF / ELSE 端口，再引用判断结果。

## 创建与运行

1. 新建工作流，输入节点声明运行时入参，输出节点声明出参并绑定来源。
2. 添加节点，连接控制边，在输入绑定中选择固定值或上游节点输出。普通节点等待所有前驱激活；互斥分支用选择节点汇合。
3. 校验并保存，在“运行工作流”填写输入。图片、视频、音频和文件上传后以受认证的资产引用传递。
4. 运行页每两秒同步节点状态，按本次运行快照的 DAG 拓扑分层展示，上游在前、下游在后，同层按定义顺序稳定排列；跳过、失败或并行执行不会改变展示位置，历史运行采用相同规则。可展开输入、输出、耗时、事件和错误。失败包含节点与运行追踪 ID；历史详情使用当时的不可变定义快照。
5. 可以取消活动运行。中止等待、离开页面或关闭浏览器不会自动取消后台任务；服务重启会将中断任务标记失败，不自动重试可能计费的步骤。

每个工作流恰好一个输入和输出节点。类型为 `string`、`float`、`integer`、`boolean`、`object`、`image`、`video`、`audio`、`file`，所有类型均可声明数组。工作流通用参数可选择“枚举 · string”，从同一连通链路中 AIGC 节点的枚举入参复制选项；选项以字符串保存和传递，兼容普通字符串参数。类型来源允许位于下游，不产生反向执行依赖。枚举来源、接口或选项变更后，需重新选择或更新枚举选项；运行前校验并明确拒绝失效定义。字符串化后存在歧义的枚举不能作为通用枚举来源。AIGC 参数继承接口的枚举选项，固定值通过下拉框选择并保持真实类型。引用上游输出时，以字符串精确匹配唯一枚举选项并还原其真实类型，例如 `"20"` 转为数值 `20`、`"false"` 转为布尔 `false`；不裁剪空白、不模糊匹配。无匹配、类型不支持或字符串化后存在歧义时，在提交 AIGC 任务前报错。字段名使用英文字母、数字和下划线，不能以数字开头。`0` 和 `false` 是有效值；必填参数不接受 `null`。

## 名称、说明与参数编辑

编排页顶部提供带标签的工作流名称和多行说明编辑区，保存后列表与 Agent 的 `workflow_list`（list/get）、`workflow_get_parameters`、`workflow_get_definition` 同步返回说明。缺少说明的旧定义在读取时按空字符串处理，不需要迁移历史数据。版本冲突仍要求重新加载，运行历史保留当时的定义快照。

每个输入参数独立分组，显示名称、类型、说明、值来源和值控件。AIGC 参数继承完整接口类型与范围，类型只读；模型和 Agent 的 prompt、媒体输入，以及已声明的输出绑定类型也固定。脚本自由输入与条件操作数仍允许选择常量类型。媒体固定值使用上传控件，数组和 JSON 参数使用结构化编辑。

输入、输出及其他可编辑参数列表支持上下箭头调整顺序。移动保留参数名、说明、默认值、枚举约束和对应绑定；首尾越界按钮禁用。运行表单和工具返回的参数数组遵循保存后的顺序。

AIGC 参考组默认保留逐项拆分输入，也可切换为数组输入，选择已连接上游节点的同媒体类型数组。数组按原参考组成员顺序填入槽位，剩余槽位不提供并沿用原有条件分支裁剪；不提供或空数组表示不输入参考素材。超过槽位数、非数组、空元素或媒体类型不匹配会在创建 AIGC 任务前报错，不截断、不跳过错误项。切换模式会清除本组原绑定，其他参数不受影响。

运行详情按 MIME 类型预览嵌套结果中的图片、视频和音频，同一资产去重。图片可查看大图，音视频支持 Range 分段读取和拖动播放；完整 JSON 可展开。预览与下载使用登录保护的资产路由，不缓存业务文件，其他文件默认下载。预览加载或解码异常进入全局错误提示。

## 脚本 AI 辅助

脚本框旁的“AI 辅助”使用已配置模型。输入需求后，将当前脚本、输入定义（引用来源或固定值）、输出定义和执行超时作为上下文发送；可展开查看实际发送的节点上下文，不附带其他节点脚本、历史运行内容或文件二进制。引用输入类型取自上游输出定义，固定值按真实类型提取，未知或混合类型不会猜测。

提示词明确 QuickJS 的同步函数体、`inputs`、`return` 对象及完整输出契约，要求保留 `0/false`、显式校验边界并提供具体异常，禁止网络、文件、Node、异步和伪造资产。无法满足当前定义时模型应说明缺失条件。服务端拒绝空响应、截断和语法错误；语法检查在独立 QuickJS Worker 中只编译，不执行生成脚本。

模型选择框右侧的思考图标可选择强度，默认使用模型自身行为，只提供模型声明支持的等级；不支持思考的模型禁用该控件。切换模型会重置为模型默认。思考强度随本次生成请求发送，不修改工作流运行节点的模型配置。

生成过程流式展示模型接口实际返回的思考内容和正文，思考区域可折叠。点击“取消生成”保留已接收内容供查看；关闭抽屉、离开节点或断开连接也会中止请求。取消、断流、上游错误或语法检查失败的残缺输出不可应用，错误通过全局弹窗呈现。

生成完成并通过语法检查后，需点击“应用到脚本”，再保存工作流。节点上下文、模型、思考强度或需求变化时，旧候选不可应用，需要重新生成。本功能不再设置 120 秒总时长限制；仍最多两个同时生成、不自动重试，Provider 自身的连接或超时规则仍然有效。语法通过不能代替运行测试，实际输出类型仍在执行时校验。

`POST /api/v1/workflows/script-assist` 使用 `Accept: text/event-stream` 获取单次生成流，事件包括 `started`、`thinking_delta`、`text_delta`、`validating`、`completed` 和 `error`。完成事件携带已检查的脚本；错误事件沿用错误码、消息及 `requestId`。等待期间发送心跳，不会自动重连或重复计费请求。不携带流式 Accept 的旧客户端仍获得完整 JSON 结果。

## 画布快捷操作

- 选中节点或连线后按 `Delete` / `Backspace` 删除；删除节点需确认，关联连线一并移除。输入框编辑不触发画布删除，输入和输出节点不可删除。
- 将端口拖到画布空白处，松手后选择节点类型，新节点按松手位置放置并自动连线；支持缩放、平移和触屏。判断节点保留所选 IF / ELSE 分支；从输入端口反向拖线时添加上游节点，新建判断节点使用菜单标明的 IF 出口。
- 节点菜单支持方向键、Enter 和 Escape，也可点击空白处取消；取消不会产生节点或连线。拖线创建时保持侧栏开闭状态，避免画布尺寸变化影响落点。
- 拖动时保留节点测量尺寸与选择状态，只更新移动节点的位置；新增节点不会自动缩放整个画布，需要时可使用画布的适应视图按钮。

## 节点

| 节点    | 配置与行为                                                                                                                                                                                                                                                               |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 输入    | 工作流入参名称、类型、必填、说明及标量默认值。                                                                                                                                                                                                                           |
| 输出    | 工作流出参类型和来源；媒体保留文件引用，可预览与下载。                                                                                                                                                                                                                   |
| 大模型  | 已配置 Provider 的模型、系统提示词、运行时 `prompt` 和可选 `images`。输出 `text`。可选思考等级、temperature、topP、maxTokens、frequencyPenalty、presencePenalty 与自定义 JSON。普通模型初始默认值分别为 0.7、1、4096、0、0；选择思考模型后采样参数默认留空，由模型决定。 |
| Agent   | 选择 Agent，输入 `prompt` 和可选 `files`；每次新会话或指定同一会话，可完成后归档。输出文本、会话 ID，以及回复中工作区附件引用对应的文件。遇到人工问题会停止流程，保留会话供处理。                                                                                        |
| AIGC    | 使用现有创作与运行中的已启用接口。沿用真实参数和默认值、任务进度与取消。返回 `files` 以及按接口输出顺序命名的 `output_1` 等文件数组；ComfyUI 文本/JSON 产物也以文件交付。                                                                                                |
| 判断    | AND / OR 组合等于、不等于、数值比较、包含、空和非空条件；激活 IF 或 ELSE 控制边。                                                                                                                                                                                        |
| 选择    | 按顺序取首个已执行候选值，或按条件选择两个候选之一；支持汇合未执行分支。                                                                                                                                                                                                 |
| JS 脚本 | 通过 `inputs` 访问映射值，同步 `return` 一个符合声明的输出对象。`console.log` 进入运行事件。                                                                                                                                                                             |

模型参数按协议发送。Google 自定义 JSON 使用生成配置字段，例如 `{"topK":40}`；OpenAI/Anthropic 使用请求参数字段。自定义同名字段覆盖常见参数，不能覆盖模型、消息、工具、凭据或网络连接。非 Completions 协议的惩罚参数必须为 0；不支持的显式参数由接口明确报错。Anthropic 设置非默认 topP 时只发送 topP，不同时发送温度。思考等级受模型能力及 SDK 支持范围限制。

JS 使用独立 Worker 内的 QuickJS WebAssembly 沙箱，不提供 Node、文件、网络或宿主 API，不支持 Promise。执行时间可设为 100–5000ms，内存上限 32 MiB，栈 256 KiB，最多 30 条日志。示例：

```js
// 输入 value 引用上游文本，输出 result 定义为 string。
console.log("转换文本");
return { result: String(inputs.value).toUpperCase() };
```

## Agent 工具与授权

勾选“开放给 Agent”后，工作流才出现在工具清单中。还需在 Agent 的工具白名单独立开启相应工具；存量和默认 Agent 不自动获得权限。**发布整个工作流意味着允许调用者执行其中配置的模型、目标 Agent 和 AIGC 接口**，无需再授予调用者每个子节点的独立工具权限。仅发布可信流程；工作流 Agent 节点不能再次调用工作流，防止递归和会话死锁。

| 工具                      | 参数                                                                                                     |
| ------------------------- | -------------------------------------------------------------------------------------------------------- |
| `workflow_list`           | `action="list"`、`workflowId=null`、`offset=0` 分页；`action="get"`、真实 ID、`offset=null` 查询出入参。 |
| `workflow_get_parameters` | `workflowId`；只查询名称、说明、版本和出入参，不返回节点、连线、脚本、绑定或枚举来源。 |
| `workflow_get_definition` | `workflowId`；查询完整节点、配置、连线和绑定。                                                           |
| `workflow_run`            | `workflowId`、稳定的 `requestKey`、`parameters:[{name,value}]`；异步调用。                               |
| `workflow_run_and_wait`   | 同调用参数；等待并报告进度，聊天中止只结束等待。只需自身工具权限。                                       |
| `workflow_get_task`       | `taskId`；查询所属 Agent 的任务，成功后将媒体交付到工作区。                                              |
| `workflow_cancel_task`    | `taskId`；取消所属 Agent 的任务及活动节点。                                                              |

调用前推荐先用 `workflow_list` 获取 ID，再用 `workflow_get_parameters` 查询出入参。返回参数保留声明顺序、名称、类型、`multiple`、`required`、说明、默认值和枚举选项；不会附带枚举来源节点。仅排查内部实现时使用 `workflow_get_definition`。原有 `workflow_list` 的 `get` 模式继续兼容。新工具需在 Agent 工具权限中单独启用，不自动授予已有 Agent。

```json
{"workflowId":"从工作流列表取得的真实 ID"}
```

JSON 对象与数组是输入类型本身，工具 `value` 因此支持动态 JSON 内容，服务端按工作流定义再次验证；工具根节点仍是固定 `Type.Object`，无根级组合 Schema。媒体参数传当前 Agent 工作区相对路径，数组传路径数组；禁止任意宿主路径。查询和交付检查任务归属、当前权限及发布状态。取消仍可用于已撤销发布的自有任务，避免任务无法停止。

相同调用方会话的同一 `requestKey` 只创建一次任务；更改工作流或参数后复用该键会冲突。媒体路径参与幂等计算，重试不会因内部上传 ID 改变而重复执行。全局最多 8 个活动工作流，每调用方最多 2 个、每小时 60 次；每个工作流最多 100 个节点、400 条边，同一批最多并发 3 个节点，运行上限 30 分钟。单节点 JSON 最多 1 MiB；工具结果最多 128 KiB，超出时需在页面查看。

## 持久化、PWA 与验证

列表摘要保存在 `app/bugpaw.sqlite3` 的 `workflow_index` 表，`kind=dag`，每条记录包含工作流 ID 和独立定义文件名。完整定义保存在 `app/workflows/definitions/<工作流ID>.json`；运行快照与受控文件仍位于 `app/workflows/`。列表接口返回 `nodeCount` 而不返回 `nodes` / `edges`，编辑和运行按 ID 请求详情。ComfyUI 使用同一索引表的 `kind=comfyui` 分区，定义保存在 `app/aigc-workflows/definitions/<工作流ID>.json`。迁移、手工修改和回滚说明见 [工作流存储](14-workflow-storage.md)。新页面通过懒加载进入现有 Manifest 预缓存；离线可加载页面静态资源，不能获取业务数据、保存或运行工作流。认证 API、运行参数与产物不进入 Service Worker 缓存。

新增测试覆盖 DAG、类型、分支汇合、幂等、并行失败、取消、重启、沙箱、协议参数映射、Agent 会话与 AIGC 任务适配、权限、文件归属、HTTP 认证、路由与导航。浏览器测试使用真实构建与虚构业务 API，真实 Provider 付费调用不属于自动化验收范围。
